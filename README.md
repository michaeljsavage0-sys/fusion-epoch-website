# Fusion Epoch website

Controlled website source package prepared on 3 September 2026.

## Current control position

- Screenshot Master v1.2 remains the visual authority for the present rebuild.
- `master_visual.jpg` is stored as a normal website asset.
- The current `index.html` is intentionally minimal and preserves the visual master.
- The four application rectangles are defined as separate clickable hotspot regions.
- No validated DSS, LDSS or LPDSS runtime is modified by this repository.
- No production deployment is authorised by this package.

## Planned workflow

1. Make one controlled change at a time.
2. Test in staging.
3. Compare visual changes against Screenshot Master v1.2.
4. Audit navigation, public links, mobile behaviour and graphics.
5. Promote only an approved staging release to `fusionepoch.com`.
6. Retain a known-good prior release for rollback.
